# Somniation

Angular 22 marketing site (Tailwind v4, static prerender, Vercel). Read `docs/project-structure.md` for the
full map of the codebase before exploring; update it when you change structure, routes, or conventions.

- Planned feature: timesheet and invoicing system, described in `plan.md`.
- Commands: `npm start`, `npm run build`, `npm test`.
- Never print or commit `.env.local` (contains a Vercel token).
